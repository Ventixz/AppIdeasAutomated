Graph from Links

Type a list of links — one connection per line — and watch a network appear. The page parses your links into a real graph, lays it out with a from-scratch force-directed layout, and reads off its shape: components, degrees, cycles, and what's reachable from where.

Your links

One link per line. Separators: -> -- - , : or a space. A line with a single word is an isolated node. # starts a comment.

What the network is

Built automatically by a scheduled Claude Code routine — one project per day. See the repository README for how it works, and this project's README for the algorithm details.
