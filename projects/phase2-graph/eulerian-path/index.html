Eulerian Path

Type a list of links — one edge per line — and the page decides whether the graph can be drawn in one unbroken stroke that crosses every edge exactly once. If it can, it walks one out with Hierholzer's algorithm and animates the route, numbering each edge in the order it is crossed. This is Euler's 1736 answer to the Seven Bridges of Königsberg — the first theorem of graph theory.

Your links

One edge per line. Separators: -> -- - , : or a space. Parallel links and self-loops are kept — this is a multigraph, so each must be crossed. A lone word is an isolated node. # starts a comment.
