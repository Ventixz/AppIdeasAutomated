Flower Shop — Ordering To Go

An abstract Saleable with two subclasses — Flower (one stem) and Bouquet (an arrangement of saleables) — plus a Shop that owns the stock. The ninth task in karan/Projects' Classes category. The point is the design, not the buttons: a flower and a bouquet are priced the same way because both are Saleable (the composite pattern — a bouquet can even hold another bouquet); money is exact integer cents, never a float, so a 12-stem bouquet is exactly $33.84; and an order is atomic — if one stem is short the whole order is refused and nothing leaves the shelves. The same classes run under Node (see the README); this page just drives them.
