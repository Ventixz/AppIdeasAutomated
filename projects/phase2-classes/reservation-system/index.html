Hotel Reservation System

A Hotel of Rooms in priced RoomType sections (standard, suite, penthouse…), and Reservations that book a room for a stay — the third task in karan/Projects' Classes category. The point here is the design, not the buttons: a room cannot be double-booked for overlapping nights, rates are kept as integer cents so stay totals are exact, and the dates are half-open so a checkout and a same-day check-in don't collide. The same classes run under Node (see the README); this page just drives them with a live calendar.
