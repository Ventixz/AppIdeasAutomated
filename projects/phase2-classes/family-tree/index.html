Family Tree Creator

A Person is just a description — a name and some years — and holds no relationships of its own. The FamilyTree owns every parent→child edge and enforces its own rules. The tenth and last task in karan/Projects' Classes category. The point is the design, not the names on screen: there is one source of truth (the edges), so siblings, cousins and grandparents are derived, never stored; the tree cannot be built into an impossible shape (no cycles, no three parents); and every blood relationship — sibling, cousin, aunt, "second cousin once removed" — comes from one algorithm: the lowest common ancestor and how far each person sits below it. The same classes run under Node (see the README); this page just drives them.
