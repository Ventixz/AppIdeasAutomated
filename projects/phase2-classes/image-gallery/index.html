Image Gallery

An abstract ImageAsset and one subclass per format — JPEG, PNG, GIF, SVG — plus a Gallery that holds and displays them. The seventh task in karan/Projects' Classes category. The point is the design, not the buttons: the gallery never switches on format, it asks the object; transforms (crop, scale, rotate) compose as exact geometry so scaling by ×½ then ×2 is the original to the pixel; and format conversion is honest about loss — a transparent PNG saved as JPEG says it flattened the alpha, it doesn't drop it in silence. The same classes run under Node (see the README); this page just drives them.
