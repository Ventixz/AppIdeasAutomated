Recipe Creator and Manager

A Recipe holds its ingredients, title, category and steps; a RecipeBook stores them and organises them by category or by main ingredient. The sixth task in karan/Projects' Classes category. The point is the design, not the buttons: every amount is an exact rational with a unit, so scaling a recipe to a new number of servings is exact (⅓ of a cup, then ×3, is a cup again — not 0.9999); the book's category and ingredient views are a derived index that can't drift from the recipes; and “what can I make?” compares quantities in a shared unit and is honest when it can't (grams vs. cups needs a density, so it says so rather than guessing). The same classes run under Node (see the README); this page just drives them.
