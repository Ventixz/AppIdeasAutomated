Inverted Index

The data structure behind full-text search. Drop in a handful of text files and this builds, in memory, a map from every word to the sorted list of files that contain it — its postings list. A query is then answered by merging a few short lists instead of re-reading every file. Supports AND, OR, -not and "exact phrases", ranks hits by TF-IDF, and checks every result against a brute-force scan.
