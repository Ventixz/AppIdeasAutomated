About

Contribution Tracker records your charitable giving and rolls it up into monthly and yearly analytics.

This project was built automatically by a scheduled Claude Code routine, one app per day, from the app-ideas Contribution Tracker spec.

🐙 app-ideas on GitHub 🤖 Claude Code

Per the spec, transactions are not kept in localStorage. They live in an IndexedDB database in your browser, and you can export them to a JSON or CSV file at any time.
