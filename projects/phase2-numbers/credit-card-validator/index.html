Credit card validator

Type a card number and this checks it with the Luhn algorithm — the checksum every card number carries — names the network from its leading digits, and verifies the length. It all runs offline: no network request, no data leaves the page. It validates structure, not a real account — a Luhn-valid number can still be a card that was never issued.

—

    The number never leaves your browser. These are checks on the digits, not a lookup of a real account.
