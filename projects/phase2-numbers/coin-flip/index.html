Coin flip simulation

Flip a coin as many times as you like and read back how many heads and tails came up — plus the things a real run actually does: the longest streaks, and the proportion of heads creeping toward the coin's true bias as the flips pile up (the Law of Large Numbers). Every run is seeded, so the same seed replays the exact same coins. All offline: nothing you do leaves the page.

    How it works

    Randomness comes from a seeded generator (mulberry32, with word-seeds hashed by xmur3), never Math.random() — so a seed is a promise: the same seed and count always produce the identical coins. That is what lets the test suite assert exact head and tail counts. One pass over the flips collects the totals, the longest streak of each face, and the running proportion at powers of ten, in O(1) memory — a million flips cost no more RAM than ten. The theory it is compared against is the binomial: expected heads n·p, standard deviation √(n·p·(1−p)), and an expected longest run of about log₂ n for a fair coin.
