Exact calculator

Type an expression — 0.1 + 0.2, 1/3 * 3, 2^100, sqrt(2). The four basic operators run on exact BigInt fractions, so 0.1 + 0.2 is exactly 0.3 and 1/3 is exactly one third — where eval() would hand back 0.30000000000000004. Scientific functions fall back to floating point and say so.
