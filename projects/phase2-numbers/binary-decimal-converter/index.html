Binary ⇄ decimal converter

Convert a number between binary and decimal, in either direction. Every integer runs on BigInt, so a 200-bit number converts exactly — where parseInt(s, 2) would quietly go wrong past the 53rd bit. Fractions work too: binary → decimal is always exact, and decimal → binary tells you when it had to round.
