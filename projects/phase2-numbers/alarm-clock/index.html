Alarm clock

Set alarms for a clock time — once, every day, weekdays, weekends or a custom set of days — or start a countdown timer. When one rings, the page beeps (Web Audio, no files) and you can snooze or dismiss. The whole schedule is driven by a DOM-free core in alarm-core.js, the same file the tests run under Node. Alarms live in this browser only (localStorage).
