Number names

Type a number and read it back in words — 1234 becomes one thousand two hundred thirty-four. Everything runs on BigInt, so a 200-digit integer is named to the last digit, and the scale words don't run out: past the everyday ones the Conway–Wechsler system generates the Latin -illion names all the way to a centillion (10303). All offline: nothing you type leaves the page.

The other direction — words back to a number

Naming a number is only half the job. Type the words and it parses them back to an exact integer — which is how the test suite proves the naming is right, by round-tripping every value through both halves.

How the big names are built

A number is chopped into groups of three digits. Group 0 (the last three) has no scale word; group 1 is thousand; group 2 is million, and so on. Past the familiar list, the name for the z-th -illion is assembled from Latin roots for the units, tens and hundreds of z — with the Conway–Wechsler combining letters that turn, say, tre + centi into tres​centi — a trailing vowel is dropped, and illion is added. That is why index 100 is a centillion and index 23 is a tresvigintillion, without any of them being stored in a list.
