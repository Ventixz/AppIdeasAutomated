Complex number algebra

Type complex numbers the way you'd write them — 3 + 4i, -i, 2.5e-3 - 1.5i — pick an operation, and see the result both as algebra and as co-ordinates on the complex plane. Division uses Smith's algorithm and the modulus uses hypot, so inputs like 1e200 + 1e200i divide correctly where the schoolbook formula overflows. All offline: nothing you type leaves the page.
