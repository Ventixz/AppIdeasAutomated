Report Generator

Builds reports from a sample sales database — grouped subtotals, crosstabs, rankings and a day's activity digest — then renders the same report as a table, text, CSV, Markdown or JSON.

What's interesting here

    
    
      
  • Control-break subtotals. The region report groups by region then
      category; each region's subtotal lands right after its own rows, and every
      total is recomputed from the raw order lines — so an average is over the
      whole group, never an average of averages.
    • 
      
  • Pivot / crosstab. "Category by Month" turns one column's values
      into columns. The month set is discovered from the data, sorted, and empty
      cells are a real 0; row totals and column totals reconcile to
      the same grand total.
    • 
      
  • One model, many renderers. Switch the Output selector — the
      figures never change shape, because every renderer formats numbers through
      the same function in the model.
