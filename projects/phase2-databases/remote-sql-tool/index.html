Remote SQL Tool

Connect to a database over the wire — the PostgreSQL protocol, hand-written.

karan/Projects · Databases 2/7

A real SQL tool connects to a remote server across the Internet, so the hard part isn’t the SQL — it’s the wire protocol: framed bytes, a login handshake, a typed row stream. This page speaks PostgreSQL’s v3 protocol from scratch (no pg library; even the SCRAM-SHA-256 crypto is hand-written). Browsers can’t open raw TCP, so the “server” below is an in-page backend that speaks the same protocol — the handshake is genuine. The companion cli.js points the exact same client at a real server over TCP. Watch the protocol trace to see every byte exchanged.
