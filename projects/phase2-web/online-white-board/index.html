Collaborate online

Share this board with others in real time, with no server. Open this same page in another browser tab or window — paste the room link into it — and every stroke, shape and note appears on both at once.

How it works: each tab is an independent replica. Edits travel between them as operations on a shared BroadcastChannel, and the board you see is computed from the set of operations ordered by a Lamport clock — so the tabs always converge, whatever order edits land in. Swap the channel for a WebSocket and the same engine works across the internet. (BroadcastChannel links tabs in the same browser; it's the honest, serverless version of the collaboration the engine is built for.)
