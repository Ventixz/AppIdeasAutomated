Page Scraper

Pull every link and image out of a page — and resolve each one into a real absolute URL, the RFC 3986 way.

Why paste HTML instead of a URL?

A page in your browser cannot fetch another site's HTML — the same-origin policy blocks the cross-origin read, and that is a security feature, not a bug. Real scrapers run on a server (see scraper-node.js in this folder, which fetches over https with zero dependencies). This demo takes the HTML you already have and does the part that is actually hard and identical in both places: finding and resolving the references.

Part of a daily automated Claude Code routine. Source task: karan/Projects → Web → Page Scraper. The engine (scraper-core.js) is shared by this page, the Node CLI, and the tests.
