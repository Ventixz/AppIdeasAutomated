Decode a real 48-byte NTP packet (hex)

Paste the 48 bytes of a server reply as hex (spaces/newlines fine). This is exactly what ntp-node.js receives over UDP — the page parses it with the same ntp-core.js. A sample stratum-1 reply is pre-filled.

A browser can't send a UDP datagram, so this page simulates the exchange and decodes real packet bytes — the arithmetic (offset, delay, the 1900-epoch 64-bit timestamp) is the identical ntp-core.js that the Node client and the tests use. For a live query run node ntp-node.js time.cloudflare.com.
