Bulk Thumbnail Creator

Generating thumbnails for a batch of images looks embarrassingly parallel, so the naive "threaded" version is one line: await Promise.all(files.map(makeThumbnail)). That launches every job at once — thousands of decode buffers and file handles alive together — and throughput collapses under the thrash while the first broken file rejects the whole batch. This one uses a bounded worker pool: a fixed crew pulls jobs from a shared queue, so in-flight work is capped no matter how big the batch is, slow jobs self-balance, and a bad file is isolated as a failure while the batch rolls on. Second of two tasks in karan/Projects' Threading category. The same engine thumbnails real PPM files under Node (see the README); this page does real canvas resizes so you can watch the pool work — and sabotage it.

Worker lanes

One row per worker in the pool. The number of rows is the only thing that bounds how much runs at once — the batch can be 10 or 10,000 and the lane count never changes. Watch a worker that draws a slow job fall behind while the others keep pulling: the queue balances itself.
