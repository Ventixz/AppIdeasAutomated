    How does this actually work?

    Every name is just a sequence of letters. The network reads names one character at a time and learns to predict the next letter given everything it has seen so far — including a special “end of name” marker so it learns where names stop. That prediction is a probability distribution over the alphabet.

    The model is a GRU cell — update and reset gates over a hidden state — with a softmax output layer, trained by backpropagation through time with the Adam optimiser. All of that math is hand-written in plain JavaScript in rnn.js; the loss curve above is the network genuinely getting better in real time.

    To generate, we sample the next letter from the learned distribution and feed it back in. Your prefix simply seeds the hidden state before sampling begins. The creativity slider is the softmax temperature.
