Whois Search Tool

Enter a domain or an IP address and see who it's registered to. The tool is honest about the three things that make WHOIS harder than a single HTTP call: it works out which server to ask (every TLD has its own registry; IPs go to a regional registry), it follows the referral — .com/.net are thin, so the registry only points at the registrar that holds the real record — and it parses the free-form text that every registry formats differently, normalising dates, EPP status codes and GDPR redaction into one record. The same engine runs under Node against the live port-43 servers (see the README).

Try: google.com example.org example.co.uk 8.8.8.8 example.com doesnotexist-zzzz.com

About the data. A browser can't open a TCP port-43 socket, so this demo runs the real engine over a small set of bundled, real-shaped WHOIS snapshots (whois-fixtures.js) — enough to light up every path: a thin .com that referral-hops to its registrar, a thick GDPR-redacted .org, a .uk with its own date grammar and indented name-server block, an IP that hops IANA → ARIN, and a "no match". Point the same code at live servers with whois-node.js and nothing in the engine changes.

Built automatically by the daily Claude Code routine described in the repository README. See the project README; the engine lives in whois-core.js and is covered by tests.js (72 checks).
