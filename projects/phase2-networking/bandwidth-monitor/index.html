Bandwidth Monitor

A live network throughput monitor — the honest kind. It reads a cumulative byte counter, turns it into a rate the way a real monitor must (coping with counter wrap and interface reset), and keeps a running total over several days. The same engine reads real /proc/net/dev counters under Node.

A browser can't read your NIC's counters, so the demo feeds the engine a simulated (but genuinely cumulative) counter — and one source reads real bytes this page has downloaded via the Resource Timing API. The rate math, wrap/reset handling and daily rollup live in bandwidth-core.js; bandwidth-node.js binds the same engine to real /proc/net/dev counters, exercised by tests.js (24 checks).
