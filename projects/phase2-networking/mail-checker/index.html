Mail Checker

Take a username and password and check the mail over POP3 or IMAP — and watch the two protocols answer the question differently. POP3 can only tell you how many messages are spooled; it has no idea which are read. IMAP tracks per-message flags, so it reports unseen and recent counts too. The engine below speaks the real wire protocol — see the live session log as it runs — and the same engine drives real TCP/TLS sockets under Node (see the README and tests).
