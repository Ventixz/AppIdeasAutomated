Country from IP

Enter an IP address and find the country it's registered in. Both IPv4 and IPv6 work. The lookup is honest about the three things that make this harder than it looks: it parses the address properly (compressed IPv6 :: and all), it recognises special-use space — private, loopback, documentation — which belongs to no country, and it binary-searches a sorted range table, returning unknown rather than a guess when an address falls in a gap. The same engine runs under Node against real registry data (see the README).

Try: 8.8.8.8 133.11.22.33 1.1.1.1 2606:4700::1111 2001:200::1 192.168.1.1 127.0.0.1 169.254.0.1 ::ffff:10.0.0.1 203.0.200.1

    What "country" means here. This returns the economy a block was delegated to by its Regional Internet Registry — which is what the task's "registered in" asks for, and what the RIR statistics files record. It is not a precise geolocation: a block registered to one country can be routed in another. The built-in data is a tiny illustrative snapshot of real, well-known registrations, written in the RIR delegated format and parsed by the same code that ingests a full registry file under Node.

    Built automatically by the daily Claude Code routine described in the repository README. See the project README; the engine lives in geoip-core.js and is covered by tests.js (54 checks).
