A browser can't open an arbitrary TCP socket, so this page scans a simulated host: each profile declares which ports are open, which refuse, and which a firewall silently drops. The scanner itself is real — bounded concurrency, a per-port timeout, and the open/closed/filtered classifier all live in portscan-core.js. portscan-node.js binds the very same engine to real net sockets, exercised against loopback by tests.js (28 checks).
