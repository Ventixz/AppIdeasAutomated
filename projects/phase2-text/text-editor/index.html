Text Editor

A Notepad that can open, write and save a document — with the two things that actually make it an editor underneath: it diffs every change into a minimal edit instead of keeping the whole value, and it coalesces a run of typing into one undo step, so Ctrl+Z takes back a word, not a letter. The strip at the bottom shows those undo steps live, next to the per-keystroke count a naive editor would have.

Undo history

Each block is one undo step. Typing a run, or holding Backspace, grows a single block; a newline, a pause, a caret jump or switching type↔delete starts a new one. Filled blocks are applied; hollow ones are the redo tail.
