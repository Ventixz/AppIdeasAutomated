Caesar · Vigenère · Vernam

Three classical ciphers that are really one idea at three scales: add a fixed number to every letter (Caesar), change the number every letter with a repeating keyword (Vigenère), or make the key as long as the message, random, and used once (Vernam, the one-time pad). The first two are broken on this very page — no key required — so you can watch why only the third is unbreakable.

Caesar — shift every letter by a fixed amount

Only 25 useful shifts exist, which is exactly why it's trivial to break. The key letter below is the Vigenère key this shift is equivalent to.

Vigenère — a repeating keyword picks the shift

Each letter of the key is its own Caesar shift, cycled across the message. Non-letters pass through and don't consume a key position.

Vernam — the one-time pad

XOR over raw bytes with a key at least as long as the message. Used once with a truly random key, it is the only cipher proven unbreakable. This page refuses a key that's too short, because a repeated pad is no longer a one-time pad.

Break it — recover the message with no key

Paste Vigenère ciphertext (or use the sample). The index of coincidence guesses the key length; chi-squared frequency analysis then solves each column as a Caesar. This is why these ciphers are history, not security.

The two-time pad

A one-time pad is perfect — once. Encrypt two messages with the same key and the key cancels when you XOR the ciphertexts, leaking P1 XOR P2. Below, both messages share a pad; the key never appears in the recovery.
