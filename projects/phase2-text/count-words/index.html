Count Words in a String

Everyone writes str.trim().split(/\s+/).length and calls it done. It scores the empty string as one word, counts :) and !!! as words, and can't see a single boundary in 你好世界. This page counts the honest way — a token is a word only if it carries a letter or digit, split on all of Unicode's whitespace — and shows the naive answer, and the segmenter's answer, right beside it so you can see the gaps.
