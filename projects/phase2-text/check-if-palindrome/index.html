Everyone writes s === s.split("").reverse().join("") and calls it done. It reports 😀 — a single character — as not a palindrome, because split("") tears the emoji's surrogate pair in half. This page checks the honest way — by grapheme, not by byte — and lets you decide what "the same backwards" should ignore.
